# Performance Benchmark Results

This file is generated by `scripts/run_benchmarks.ps1` on a machine with a C++20 compiler.

The benchmark suite reports:

- chunk throughput in MiB/s from `chunk_bench`
- average Raft append latency in ns from `cluster_bench`
- WAL replay recovery time in ms from `recovery_bench`

Local numbers were not generated in this workspace because the available compiler is GCC 6.3 and does not support C++20.
